特殊历史时期测试日期
=========================

一、新莽时期 (公元9-23年)
--------------------------
王莽代汉建立新朝，采用"建丑月"历法，即以12月（丑月）为正月。

测试点：
- 公元9年2月15日   # 新朝建立后的第一个农历新年期间
- 公元10年1月1日   # 新莽二年
- 公元14年6月15日  # 新莽六年年中间
- 公元20年1月1日   # 新莽十二年
- 公元23年10月1日  # 新莽灭亡前夕（更始政权的建立时间）

二、魏明帝时期 (公元227-239年)
------------------------------
曹魏继承东汉历法，亦采用建丑月。

测试点：
- 公元237年1月1日   # 魏明帝曹叡太和元年
- 公元238年6月15日  # 魏明帝景初二年
- 公元239年12月1日  # 魏明帝曹芳登基（年末）

三、武则天时期 (公元690-705年)
-----------------------------
武则天称帝建立周朝，曾改用"建子月"（以11月为正月），即周历。
后又曾用建丑月。

测试点：
- 公元690年1月1日   # 武则天永昌元年（实际是周历正月）
- 公元690年9月9日   # 重阳节，历史上武则天在此日登基
- 公元691年1月1日   # 武则天周历二年
- 公元695年1月1日   # 武则天周历四年（天册万岁元年）
- 公元700年1月1日   # 武则天圣历三年

四、正常历史时期（对比组）
------------------------
用于验证非特殊时期时，算法与标准夏历一致。

测试点：
- 公元200年1月1日   # 东汉末年
- 公元500年1月1日   # 南北朝南齐
- 公元1000年1月1日  # 北宋咸平三年
- 公元1500年1月1日  # 明弘治十三年
- 公元1800年1月1日  # 清嘉庆五年
- 公元1900年1月1日  # 清光绪二十六年
- 公元2000年1月1日  # 现代

五、公元前时期
-------------
测试远古时期的算法稳定性。

测试点：
- 公元前221年1月1日 # 秦始皇统一六国之年
- 公元前100年1月1日 # 西汉时期
