# 实验性功能 (Experimental Features)

以下功能已实现并可使用，但由于缺乏广泛的流派共识或历史验证数据，标记为"实验性"。它们在未来版本中可能调整行为或接口。

---

## 1. 五虎遁推宫干基准 (`wuHuDunBasedOn`)

**配置项**：`CalendarOptions.wuHuDunBasedOn`（Dart）/ `main_rules.json` → `wu_hu_dun_boundary`（JSON）

**可选值**：`lunar`（默认）/ `solar`

**影响**：五虎遁用于推算宫干（天干排列），其核心输入是"年干"。此选项决定使用哪个年干：

| 值 | 行为 |
| :--- | :--- |
| `lunar` | 使用**农历年干**。立春后、春节前出生的人，年干仍属旧年。 |
| `solar` | 使用**节气年干（八字年柱天干）**。立春后即算新年干。 |

两者在立春和春节之间出生的人会产生差异，这个看似微小的年干变化会引发**整个命盘的蝴蝶效应**：
**年干**改变 → 导致十二宫的**宫干**全部改变 → **命宫天干**改变 → 导致**五行局**改变（如水二局变成木三局） → 导致**紫微星**及所有十四主星的位置全部改变 → 同时影响起运时间、大限排列以及所有的飞宫四化。可以说，这个基准一变，排出来的几乎是两张完全不同的命盘。

## 2. 流运分界线 (`flowLimitBasedOn`)

**配置项**：`CalendarOptions.flowLimitBasedOn`（Dart）/ `main_rules.json` → `flowLimit_boundary`（JSON）

**可选值**：`lunar`（默认）/ `solar`

**影响**：控制流年、流月等层级的时间分界方式：

| 值 | 行为 |
| :--- | :--- |
| `lunar` | 流年以**农历年**为界，流月以**农历初一**为月界。 |
| `solar` | 流年以**立春**为年界（与八字年柱一致），流月以**节气交节时刻**为月界。 |

选择 `solar` 时，整套流运体系更接近八字的推算逻辑，立春前出生的人会被算入上一年的流年。

## 3. 历史历法保护 (`enableHistorical`)

**配置项**：`CalendarOptions.enableHistorical`（Dart）/ `main_rules.json` → `enable_historical`（JSON）

**可选值**：`true`（默认）/ `false`

**影响**：中国历史上经历过多次历法改革，部分特殊时期（如太初历以前、武则天周历等）的闰月和月序与现代推算结果存在偏差。此开关会同时影响**本命原局**和**流运推演**：

| 值 | 行为 |
| :--- | :--- |
| `true` | **本命盘**：开启历史特殊历法解析（如将公元前 366~104 年颛顼历期间的闰九月正确解析命名为“后九月”）。<br>**流运盘**：检测到历史“历法红区”时，**自动熔断流月及以下层级的计算**（受限于历史不确定性，仅排原局和大限/流年），`TimelineManifest.status.isHistoricalRedZone` 会被标记为 `true`。 |
| `false` | 关闭保护，无论年代强制使用现代历法规则推算所有层级。结果在历法混乱时期可能严重偏离史实记载。 |

> [!WARNING]
> 关闭此保护后，远古时期的流月/流日结果仅供参考，不保证与史实历法一致。

## 4. 童限处理方式 (`childhoodRule`)

**配置项**：`CalendarOptions.childhoodRule`（Dart）/ `main_rules.json` → `childhood_decade`（JSON）

**可选值**：`skip`（默认）/ `regular`

**影响**：起运前的"童限"阶段如何展示：

| 值 | 行为 |
| :--- | :--- |
| `skip` | **口诀跳跃派**。根据传统口诀（"一命二财三疾厄，四妻五福六官禄"）确定每岁的童限所在宫位，每年在特定宫位间跳跃。 |
| `regular` | **顺延派**。从命宫起，随着虚岁增长，每年依次移动一格。其**移动方向（顺/逆）与大限走向保持一致**（即：阳男阴女顺行，阴男阳女逆行）。 |
